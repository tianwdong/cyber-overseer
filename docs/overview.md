# 总览页

默认打开总览，任务页保留原有列表、搜索和详情。总览展示正在看护的任务统计、待接手事项、最新三条收工结果以及 Codex 账户额度。

- 工作中仅统计明确运行的看护任务；恢复中与待处理沿用核心状态汇总。
- 待处理卡按完整任务 ID 进入详情，不触发恢复或审批。
- 结果卡展示原回复摘录，点击展开对应信箱记录并标为已读。
- 额度来自现有只读账户查询；无数据不按零处理，旧数据注明读取时间和过期状态，到达预计重置时间不擅自重置数值。
- Ctrl+F / Command+F 从总览切到任务搜索；通知打开任务同样切到任务页。
- 当前不包含额度等待队列、项目工地、自动交班或角色递信动画。

验收采用独立 Electron 演练状态，中英文截图与任务 ID 导航测试；不代表 Windows 实机或真实恢复验收。
