# Security

Cyber Overseer is an experimental local Codex Desktop adapter. Please report vulnerabilities using GitHub private vulnerability reporting on this repository. Do not include tokens, raw Codex databases, conversation logs, or unredacted screenshots in public issues.

Use a supported local Codex installation. The adapter uses internal IPC, not a stable public API. Windows named-pipe identity checks and real-machine acceptance remain pending. See [validation](docs/validation.md) and [Windows status](docs/windows-support.md).

赛博督工使用实验性本机适配器。安全问题请通过仓库的 GitHub 私密漏洞报告提交，不要在公开 Issue 中上传令牌、原始数据库、对话日志或未脱敏截图。Windows 管道身份与真机验收仍待完成。
